# Today

Route: `Main` → tab key `today` (default tab)
Summary: The day's ledger page — one row per project with tasks on the `today` list, a habits section with one row per habit that opens that habit's timer page, "New project" and "New habit" rows that open the add sheet, and a wax "page closed" stamp once everything is struck through.

## Notes
`src/screens/TodayScreen.tsx`. The page no longer lists tasks. It renders `ProjectRows` for the `today` list — see [[Project Grouped Tasks]] — which now lists every project, including ones with no task on Today, and ends with a "New project" row that opens [[Quick Add Sheet]] in project mode. The tasks themselves, with their swipe and strike-through, live one level down on [[Project Detail]]. There is no separate upcoming list any more: every dated task is on the `today` list, including the five seed tasks dated tomorrow or later in the week, which keep their day in `meta`, carry `later: true`, and appear inside their project here. A task added with unrecognised text in the sheet's When field is filed here the same way, flagged `later` with that text as its `meta` — see [[Natural Language Quick Add]].

The header trailing label still counts remaining tasks: it filters `useTasks()` to the `today` list, leaves out tasks flagged `later`, and counts those not in the `done` map in `src/state/store.tsx`, swapping to "all done" at zero, which is also the condition that reveals the stamp. The later-dated tasks therefore count toward neither, although they are included in the done/total count on their project row. Tasks snoozed or deleted on [[Project Detail]] or the Recent tab go into `cleared` and drop out of `useTasks()`, so they stop counting toward the tally — clearing the day by swiping raises the stamp just as striking every task does.

Below the header a journaling block now sits above the tag bar. A horizontal, RTL-aware journal switcher (`accessibilityRole="radiogroup"`) shows one chip per `useJournals()` — the journal icon in its colour plus its name — highlighting `currentJournalId` and calling `setCurrentJournal` on tap. Under it, a daily-note card reads the entry in `entries` where `journalId === currentJournalId && day === dayKey(new Date())`: when it exists the card shows the title (or first body line) and a two-line snippet and opens [[Entry Composer]] with that id; when it does not it shows `todaysPrompt` + `promptForDate` and an `openTodaysNote` button that opens the composer with `null`. The card's header carries the `useStreak()` writing streak via `StreakTallyIcon` + `dayStreak`, falling back to the `streakNudge` line at zero. An On This Day section renders only when `useOnThisDay()` is non-empty — a `SectionLabel` plus one row per memory labelled with `relativeYears`, each opening its entry in the composer. A "Timeline & map" affordance calls `onOpenTimeline`. See [[Daily note]], [[Daily writing prompts]], [[Multiple journals]], [[Journaling streak + nudge]], [[On This Day]], [[Timeline and map view]]. The two screen props `onOpenEntry(entryId | null)` and `onOpenTimeline()` carry these out to navigation.

Between the On This Day section and the "Timeline & map" affordance, a read-only device-events strip renders only when `useDeviceCalendarEvents(startOfToday, startOfToday + 1 day)` returns at least one event — see [[Device calendar overlay]]. It is styled like the On This Day block (an `events` `SectionLabel` plus one presentational, non-pressable row per event): each row shows the event time via `formatTime` (or the `allDayEvent` label), an optional calendar-colour dot, and the title, and carries a combined `accessibilityLabel`. The strip degrades to nothing when the device-calendar pref is off or access is denied, so there is no empty box.

The habits section lists every habit from `useHabits()` — the seeded one first, then any the user has added — one row each: a moss circle, the habit name, its target time, and a streak tally. The target is the habit's `minutes`, drawn as "30 min" in `ink3` monospace after the name only when it is above zero — 30 for the seeded habit, and whatever was entered in the add sheet for the others. Each row is a `Pressable` that opens [[Habit]] with that habit's id, and its circle fills moss once `habitSessions` in the store holds at least one session for that habit — see [[Habit Session Timer]]. The tally is drawn only when the habit's `streak` is above zero, which is the seeded habit alone: its 12 is a fixed value, and added habits start at 0 and show none. The section ends with a "New habit" row that opens [[Quick Add Sheet]] in habit mode — see [[Add Habits and Projects]]. The whole section, and the "New project" row above it, is hidden while the search field has text, and returns when it is cleared.
