## Notes
`src/screens/SettingsScreen.tsx`. Three rows are live and write straight to the theme context: Language toggles en/ar, Appearance is a three-way `Segmented` for light/dark/auto, and Reduce motion is a `Toggle`. The journaling block adds three live toggles backed by the store prefs: a daily writing reminder (`reminderEnabled` at `reminderTime`), automatic context capture (`contextEnabled`), and an On This Day notification (`onThisDayEnabled`); the reminder and On This Day toggles call `scheduleDailyReminder` / `cancelReminder` through the [[Local notification module]] (`REMINDER_IDS`) and surface a denied-permission helper — see [[Journaling streak + nudge]], [[On This Day]], [[Auto context metadata (time, location, weather)]]. A Calendar section (between the journaling block and Text size) adds the device-calendar controls — see [[Device calendar overlay]]. Its `ToggleRow` (`deviceCalendarEnabled`) requests read access through `requestCalendarAccess` on enable; denial keeps the toggle off and shows the `calendarPermissionDenied` helper. When enabled and granted, `listDeviceCalendars` loads a multi-select source picker — a leading "All calendars" row (meaning `deviceCalendarIds = []`) plus one `CalendarPickRow` per calendar (`accessibilityRole="checkbox"`, colour dot, 44pt target), persisted via `setDeviceCalendarIds`; an empty list shows the `noCalendars` helper. Week start, text size, sync and sharing render their values but are not editable. Shortcuts is wired as a `Pressable` and is the sole entry point to [[Swipe States]]. A Security group (after the Calendar section) holds the App lock `ToggleRow` (`appLockEnabled`): enabling verifies biometric hardware + enrollment and runs a confirming prompt, reverting with the `appLockUnavailable` helper on web / no-hardware / cancel — see [[Biometric app lock]]. A Data group at the end holds two action rows, "Export as JSON" and "Export as Markdown", that build the export and share it through `expo-sharing` — see [[Export JSON and Markdown]].


Phase 7 adds a Cloud sync group (after Data): an enable toggle, a "Sync now" row and a "Join a shared list" inline share-code field — see [[Cloud sync (Supabase)]] and [[Real-time shared lists (Supabase)]]. Every control no-ops with the `syncNotConfigured` helper when `EXPO_PUBLIC_SUPABASE_URL` / `EXPO_PUBLIC_SUPABASE_ANON_KEY` are unset. The static "Sync" status row is unchanged.

The Cloud sync group now leads with account rows — see [[Account sign-in (Google and Apple)]]. Signed out (and only when the client ids are set), it shows "Continue with Google" and, on iOS, "Continue with Apple" rows plus a `signInToSyncDesc` helper; signed in, it shows the account email and a "Sign out" row. `onSignIn` hands the provider ID token to `supabase.auth.signInWithIdToken` and, when sync is enabled, kicks a full `since: 0` push so local data migrates under the authenticated owner. The buttons are hidden and sign-in no-ops when auth is unconfigured.
