# Magic-plus drag insert

Status: shipped
Summary: Realised as natural-language quick add — typed dates, times and offsets schedule a task without a drag gesture — alongside the already-shipped calendar drag-to-schedule.

## Details
Phase 5 redefined the "magic plus" idea as natural-language capture rather than a plus-handle drag on the calendar. Scheduling a task from the add sheet now happens by typing: "friday", "in 3 days", "at 15:00", "noon", "tomorrow 3pm". See [[Natural Language Quick Add]] for the full token set. Dragging a task onto a day is already covered by [[Calendar drag-to-schedule]]; between the two, dropping a new task into a slot is fully served, so this enhancement is closed.
